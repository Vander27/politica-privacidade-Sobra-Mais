Política de Privacidade – Sobra MAIS

Última atualização: 28 de março de 2026

O aplicativo Sobra MAIS valoriza a privacidade dos seus usuários e se compromete a proteger as informações coletadas. Esta Política de Privacidade descreve como os dados são tratados ao utilizar o aplicativo.

1. Informações Coletadas

O aplicativo Sobra MAIS pode coletar as seguintes informações:

  • Dados inseridos pelo usuário (listas de compras, produtos, valores)
  • Informações básicas do dispositivo (como modelo e sistema operacional)
  • Dados de uso do aplicativo (interações e funcionalidades utilizadas)

Importante: O aplicativo não coleta dados pessoais sensíveis, como:

  • CPF
  • Dados bancários
  • Senhas

2. Uso das Informações

As informações coletadas são utilizadas para:

  • Melhorar a experiência do usuário
  • Salvar e organizar listas de compras
  • Gerar relatórios e arquivos (como PDF)
  • Aperfeiçoar funcionalidades do aplicativo

3. Compartilhamento de Dados

O aplicativo Sobra MAIS não compartilha dados pessoais com terceiros, exceto quando necessário para:

  • Cumprimento de obrigações legais
  • Serviços essenciais para funcionamento do aplicativo

4. Armazenamento de Dados

  • Os dados podem ser armazenados localmente no dispositivo do usuário
  • Em futuras versões, poderão ser utilizados serviços em nuvem (com aviso prévio)

5. Segurança

Adotamos medidas razoáveis para proteger as informações dos usuários. No entanto, nenhum sistema é totalmente seguro.

6. Direitos do Usuário

O usuário pode:

  • Excluir seus dados apagando o aplicativo
  • Parar de utilizar o serviço a qualquer momento

7. Crianças

O aplicativo Sobra MAIS não é direcionado a menores de idade e não coleta dados intencionalmente desse público.

8. Alterações nesta Política

Esta Política de Privacidade pode ser atualizada periodicamente. Recomendamos a revisão regular desta página.
